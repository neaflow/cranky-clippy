# cranky-clippy
This is Cranky Clippy. He's happy for now, but he won't be if you get distracted.

PUT THE HAPPY CRANKY CLIPPY HERE

If you find yourself getting easily distracted from the study/work goals that you set for yourself, you probably are in need of a motivator. Cranky Clippy is like the OG from the 90s versions of Word, but he lives on your desktop, and feeds on your productivity. He gets really, really mad if you dare distract yourself. So much so that he *will* take action to make sure you stay focused.
